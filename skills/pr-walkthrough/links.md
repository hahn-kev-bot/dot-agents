# Link formats

**GitHub PR**

- Overview: URL from `gh pr view`
- File: `https://github.com/{owner}/{repo}/blob/{headRef}/{path}`
  or `{pr_url}/files#{url-encoded-path}`

**Local / branch**

- `[src/auth.ts](src/auth.ts)`
- Line anchor when useful: `[src/auth.ts:40-58](src/auth.ts#L40-L58)`

Open files with `open_resource` only when the user asks — the walkthrough
links are for the reader to follow.
