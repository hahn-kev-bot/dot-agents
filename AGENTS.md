## Creating a PR
PR body layout, top to bottom:
1. An empty section for me to write about the PR myself.
2. A `---` divider, then the AI summary inside a collapsed `<details><summary>AI summary</summary>` block. When the `pr` skill is in use, its sections go inside this block.
3. The test plan, if there is one, below the block and outside it.
